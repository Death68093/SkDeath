SkDeath Documentation

Syntax reference for SkDeath, an addon targeting Matocolotoe's Skript 2.6.5-for-1.8 fork on Minecraft 1.8.8.

This documentation follows the conventions of the official Skript documentation: every syntax entry identifies its type, patterns, return type, requirements, description, and examples.

SkDeath 0.2.1 Minecraft 1.8.8 Skript 2.6.5-for-1.8 Java 8 target

Syntax Conventions

Patterns below use Skript's normal pattern notation.

NotationMeaning
%type%An expression of the specified Skript type.
[text]Optional syntax.
(a|b)One of the listed alternatives.
%string%A text/string expression.
%number%A numeric expression.
%players%One or more Bukkit players.
%scoreboard%A SkDeath scoreboard object.
%dictionary%A SkDeath dictionary object.
%npc%A SkDeath Citizens NPC object.

Types

Custom object types exposed by SkDeath.

Type

Scoreboard

Pattern:%scoreboard%
Aliases:scoreboard, scoreboards
Since:0.2.0

A SkDeath-managed sidebar scoreboard. The same object can be displayed to multiple players, making it suitable for shared/global scoreboards. Separate objects can be assigned to individual players for per-player displays.

Type

Dictionary

Pattern:%dictionary%
Aliases:dictionary, dictionaries
Since:0.2.0

A nested key-value object. Dot-separated paths such as server.players.online automatically create nested dictionaries.

Type

NPC

Pattern:%npc%
Aliases:npc, npcs, citizen, citizens
Requirements:Citizens
Since:0.2.0

A Citizens NPC controlled by SkDeath. NPC syntax is only registered when Citizens is present.

Expressions

Expressions return values that can be used in other Skript syntax.

Expression

New Scoreboard

Patterns:
  • a new (scoreboard|sidebar)
  • a new (scoreboard|sidebar) (named|with title) %string%
  • a new (scoreboard|sidebar) with lines %strings%
  • a new (scoreboard|sidebar) (named|with title) %string% with lines %strings%
Return type:scoreboard
Since:0.2.0

Creates a new SkDeath scoreboard. When a line list is supplied, lines are inserted in order starting at line 1.

set {_board} to a new scoreboard named "&c&lServer" with lines "&7Welcome", "", "&fPlayers: &a%number of all players%"
show {_board} for all players
Expression

Player Scoreboard

Patterns:
  • %player%'[s] scoreboard
  • scoreboard of %player%
Return type:scoreboard

Returns the SkDeath scoreboard associated with the player's current scoreboard state.

set line 1 of player's scoreboard to "&aHello"
set title of scoreboard of player to "&e&lStats"
Expression

Scoreboard Properties

Patterns:
  • title of %scoreboard%
  • line %number% of %scoreboard%
Return type:text

Reads the title or one stored line of a SkDeath scoreboard.

set {_title} to title of {_board}
set {_line} to line 3 of {_board}
message "Title: %{_title}%"
message "Line 3: %{_line}%"
Expression

New Dictionary

Pattern:a new dictionary
Return type:dictionary

Creates an empty dictionary.

set {_dict} to a new dictionary
Expression

Dictionary Value

Patterns:
  • value of %dictionary% at %string%
  • %dictionary%.%string%
Return type:object

Returns the value stored at a dot-separated path. The dictionary object supports nested paths such as server.players.online.

set key "server.name" of {_dict} to "SkDeath"
set key "server.players.online" of {_dict} to 7
set {_name} to value of {_dict} at "server.name"
set {_online} to {_dict}.server.players.online
Expression

Dictionary Keys

Pattern:keys of %dictionary%
Return type:text (multiple)

Returns the dictionary's top-level keys.

set {_keys::*} to keys of {_dict}
loop {_keys::*}:
    message "Key: %loop-value%"
Expression

Dictionary Values

Pattern:values of %dictionary%
Return type:object (multiple)

Returns the dictionary's top-level values in insertion order.

set {_values::*} to values of {_dict}
Expression

Dictionary Size

Pattern:size of %dictionary%
Return type:number

Returns the number of top-level entries in the dictionary.

Expression

NPC From ID

Pattern:npc from id %number%
Return type:npc
Requirements:Citizens

Retrieves an NPC created and registered by SkDeath using its numeric Citizens ID.

set {_npc} to npc from id 12
set name of {_npc} to "&aGuide"
Expression

NPC Click Type

Patterns:
  • event[- ]npc click type
  • event click type
Return type:text
Values:left, right
Requirements:Citizens; on npc activate
Expression

Placeholder

Patterns:
  • [the] placeholder [named] %string%
  • [the] placeholder [named] %string% for %player%
Return type:text
Requirements:PlaceholderAPI is required for external PAPI placeholders; local SkDeath placeholders work without it.

Resolves a PlaceholderAPI placeholder when available. If PlaceholderAPI is unavailable or a placeholder cannot be resolved, the original placeholder text is returned.

set {_rank} to placeholder named "%vault_rank%" for player
message "Rank: %{_rank}%"
Expression

Display Name

Patterns:
  • display name of %player%
  • %player%'[s] display name
Return type:text

Returns the Bukkit display name of a player. This is not the player's immutable Bukkit name.

Effects

Effects modify SkDeath objects or Bukkit state.

Effect

Scoreboard Effects

Patterns:
  • (display|show) %scoreboard% (for|to) %players%
  • hide %scoreboard% (from|for) %players%
  • set title of %scoreboard% to %string%
  • set line %number% of %scoreboard% to %string%
  • clear line %number% of %scoreboard%
  • set title of %player%'[s] scoreboard to %string%
  • set line %number% of %player%'[s] scoreboard to %string%
  • clear line %number% of %player%'[s] scoreboard
  • set %player%'[s] scoreboard to %scoreboard%
  • set scoreboard of %player% to %scoreboard%
  • destroy %scoreboard%
Since:0.2.0

A shared scoreboard is simply one scoreboard object shown to multiple players. A per-player scoreboard is achieved by creating a separate object and assigning it to one player.

set {_board} to a new scoreboard named "&c&lServer"
set line 1 of {_board} to "&fPlayers: &a%number of all players%"
show {_board} for all players

set {_personal} to a new scoreboard named "&b&lStats"
set line 1 of {_personal} to "&fPlayer: &a%player%"
set player's scoreboard to {_personal}
Effect

Dictionary Effects

Patterns:
  • set key %string% of %dictionary% to %object%
  • set value at %string% of %dictionary% to %object%
  • delete key %string% of %dictionary%
  • clear %dictionary%
  • set %dictionary%.%string% to %object%

Dot-separated paths create nested dictionaries automatically.

set {_dict} to a new dictionary
set key "server.name" of {_dict} to "SkDeath"
set key "server.players.online" of {_dict} to 12
set {_dict}.server.version to "0.2.1"
delete key "server.version" of {_dict}
clear {_dict}
Effect

Placeholder Values

Patterns:
  • set value of placeholder [(with name|named)] %string% to %string%
  • delete value of placeholder [(with name|named)] %string%
Scope:Server-wide local SkDeath placeholder map.
set value of placeholder named "server_name" to "SkDeath"
message "%placeholder named \"server_name\"%"
delete value of placeholder named "server_name"
Effect

Player Utilities

Patterns:
  • set display name of %player% to %string%
  • set %player%'[s] display name to %string%
  • delete display name of %player%
  • delete %player%'[s] display name
  • broadcast %string% to %world%

Display names are Bukkit display names and therefore can affect contexts such as chat or tab display where a plugin uses the Bukkit display name.

set player's display name to "&cAdmin"
broadcast "&aHello everyone in this world!" to player's world
delete player's display name
Effect

Citizens NPC Effects

Requirements:Citizens
Patterns:
  • set %npc% to a new (npc|citizen)
  • set %npc% to a new (npc|citizen) (named|with name) %string%
  • set %npc% to a new (npc|citizen) (of|with) type %string%
  • set %npc% to a new (npc|citizen) (named|with name) %string% (of|with) type %string%
  • set %npc% to a new (npc|citizen) (named|with name) %string% at %location%
  • set %npc% to a new (npc|citizen) (named|with name) %string% (of|with) type %string% at %location%
  • set name of %npc% to %string%
  • set %npc%'s name to %string%
  • destroy %npc%
  • set skin of %npc% to %player%
  • set skin of %npc% to url %string%
  • set left-click action of %npc% to player %string%
  • set left-click action of %npc% to server %string%
  • set right-click action of %npc% to player %string%
  • set right-click action of %npc% to server %string%
  • clear left-click action of %npc%
  • clear right-click action of %npc%
The NPC creation syntax passes the supplied type string to Citizens. Use a type accepted by the Citizens version installed on the server.
set {_npc} to a new npc named "&6Guide" of type "PLAYER" at player's location
set left-click action of {_npc} to player "say Hello"
set right-click action of {_npc} to server "say NPC clicked"
set skin of {_npc} to player

Conditions

Condition

Scoreboard Display

Patterns:
  • %scoreboard% is shown to %player%
  • %scoreboard% is not shown to %player%
Since:0.2.0
if {_board} is shown to player:
    send "&aThe board is visible."

if {_board} is not shown to player:
    send "&cThe board is hidden."

Sections

Section

For Dictionary

Patterns:
  • for %objects%, %objects% (in|of) %dictionary%
  • for %objects% (in|of) %dictionary%

The two-variable form assigns each top-level key and value. The one-variable form assigns each top-level key.

for {_key}, {_value} in {_dict}:
    broadcast "%{_key}% = %{_value}%"

for {_key} in {_dict}:
    broadcast "Key: %{_key}%"
Iteration is over the dictionary's top-level entries. Nested dictionaries are still stored as values under their parent key.

Events

Event

NPC Activate

Pattern:[on] npc activate
Requirements:Citizens

Fired when a tracked SkDeath NPC is activated by a player through a Citizens click event.

Event valueTypeDescription
event-npcNPCThe SkDeath NPC that was activated.
event-playerPlayerThe player who activated the NPC.
event npc click typeTextleft or right.
on npc activate:
    send "NPC: %event-npc%" to event-player
    send "Player: %event-player%" to event-player
    send "Click: %event npc click type%" to event-player

Compatibility

SkDeath 0.2.1 is intentionally tied to the old 1.8 Skript environment.

Target stack: Matocolotoe's Skript 2.6.5-for-1.8 fork on Minecraft/Spigot-compatible 1.8.8. Do not substitute a modern Skript build.
DependencyStatusNotes
Skript 2.6.5-for-1.8RequiredPrimary API target for SkDeath syntax registration.
Spigot/Bukkit 1.8.8Required runtime platformSkDeath uses the legacy Bukkit scoreboard/player APIs available on 1.8.8.
PlaceholderAPIOptionalUsed when resolving external PlaceholderAPI placeholders. Local SkDeath placeholder values do not require PAPI.
CitizensOptionalNPC syntax and the npc activate event are only enabled when Citizens is present.
Do not install a modern SkQuery release on this 1.8 fork unless the specific build is known to support the fork. An incompatible addon can fail while Skript is compiling unrelated script syntax.

Examples

Shared server scoreboard

command /serverboard:
    trigger:
        set {_board} to a new scoreboard named "&c&lServer"
        set line 1 of {_board} to "&7Welcome!"
        set line 2 of {_board} to ""
        set line 3 of {_board} to "&fPlayers: &a%number of all players%"
        show {_board} for all players

Per-player scoreboard

command /stats:
    trigger:
        set {_board} to a new scoreboard named "&b&lStats"
        set line 1 of {_board} to "&fPlayer: &a%player%"
        set line 2 of {_board} to "&fWorld: &d%world of player%"
        set line 3 of {_board} to "&fHealth: &c%health of player%"
        set player's scoreboard to {_board}

Nested dictionary

set {_data} to a new dictionary
set key "server.name" of {_data} to "SkDeath"
set key "server.version" of {_data} to "0.2.1"
set key "player.name" of {_data} to player's name
set key "player.stats.health" of {_data} to health of player

set {_health} to {_data}.player.stats.health
message "Health: %{_health}%"

NPC interaction

command /guide:
    trigger:
        set {_npc} to a new npc named "&6Guide" of type "PLAYER" at player's location
        set left-click action of {_npc} to player "say You left-clicked the guide."
        set right-click action of {_npc} to server "say The guide was right-clicked."
        set skin of {_npc} to player

on npc activate:
    send "&7You clicked &e%event-npc% &7with &e%event npc click type%&7." to event-player

Not currently implemented

The following ideas are part of the broader SkDeath design but are not registered by version 0.2.1.

  • Literal dictionary syntax such as { key: value }. The 1.8 Skript parser already gives braces special variable meaning, so SkDeath currently uses a dictionary object API instead.
  • Numeric scoreboard scores/objectives exposed as a separate SkDeath API.
  • Full Citizens action-type/type-specific abstractions beyond the current string-based creation and action interfaces.
  • Additional player utilities beyond display names and world broadcasts.
